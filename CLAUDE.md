## What this is
- An RL environment (Gymnasium-style JSON `reset/step`) for training AI financial
  auditors: synthetic company generator with hidden errors, read-only investigation
  tools, matcher and terminal reward. Spec: the FinTech case of Genesis Hackathon 2026 (not in the repo).
- Repo: https://github.com/madiyar-abi/genesis (public), default branch `main`.

## Hackathon context
- Genesis Hackathon, online stage. Case published 2026-11-19 12:00. Final deadline **2026-11-22 22:00**
  (PDF says 23:59 Astana; we plan for 22:00).
- Submit the shared Drive folder containing the repo link, demo video and optional presentation.

## Stack
- Python 3.11 (`uv python install 3.11`), dependencies pinned, stdlib preferred.
  No network, paid APIs or GPU at check time. Docker not installed locally:
  keep a `Dockerfile`, verify with `uv run`.

## Run / test / build
- Install: nothing — stdlib only, zero runtime deps (`uv` just provides Python 3.11).
- Full check (the jury's single command): `uv run python -m auditenv.check` (exit 0 = pass).
- Test: `uv run python -m unittest discover -s tests -t .`; one module: `uv run python -m unittest tests.test_env`.
- Verifier: `uv run python -m auditenv.verify --seeds 0-199`. Demo: `uv run python -m auditenv.demo`.
- Re-export episodes after any generator change: `uv run python -m auditenv.export --config configs/dev.json --out episodes/dev`
  (same for train), then regenerate `trajectories/` and `trajectories.jsonl` (see README) — committed files must match the code.
- Lint/format: none configured; match the surrounding style (PEP 8, 120 cols).

## Where things live
- Interfaces are fixed in `docs/CONTRACT.md` — change it first, then code.
- `auditenv/generator.py` + `inject.py` build episodes; `env.py` is the reset/step API; `matcher.py`
  is the shared grader; `verify.py` independently re-derives truth from records.
- `configs/` versioned episode lists; `episodes/` exported data (generated — don't hand-edit);
  `trajectories/` generated by `auditenv.run`.

## Conventions
- Money = int minor units, FX rates = decimal strings, `Decimal` for conversions — never float.
- Anything grader-side (truth, provenance, seed, grading result) must never reach an observation or `info` in eval mode.
- Tests: `tests/test_<module>.py`, stdlib `unittest`; generator changes must keep `auditenv.verify` at 0 problems.
- Commits: small, one logical change each, clear message.
- Work on a feature branch and open a PR into `main`; never push directly to `main`.

## Team / repo hygiene
- Personal editor and machine config stays out of git (`.vscode/`, `.idea/`,
  `.DS_Store`, `.env*`, `.claude/settings.local.json`, `CLAUDE.local.md`) —
  see `.gitignore`. Never commit files that only work on one machine.
- Secrets live in env vars only. Never write a real key into any tracked file.
- Personal notes for the agent go in `CLAUDE.local.md` (ignored), not here.

## Do NOT touch
- `episodes/`, `trajectories/`, `trajectories.jsonl` only via their generators.

## Gotchas
- `uv run` does not install the package (`package = false`): run modules from the repo root (`python -m auditenv.x`).
- Expense journals carry no ids — group them by timestamp when checking balances.
- Truth amounts are in the base currency (ledger misstatement), never the document currency.
